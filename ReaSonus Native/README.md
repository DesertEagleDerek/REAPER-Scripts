# ReaSonus Native

These scripts were created for use with [ReaSonus Native](https://github.com/navelpluisje/Reasonus-Native) and will not work properly unless it is installed and a supported control surface is connected and active in the current REAPER session.

## API Demo

Small demo scripts to show API commands working in a limited capacity. Ideal for familiarising yourself with the API.

## API Script

Full scripts that serve a purpose while mixing. These are either personal scripts or were created to satisfy a users request.
