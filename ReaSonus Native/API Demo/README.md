# API Demo

Small demo scripts to show API commands working in a limited capacity. Ideal for familiarising yourself with the API.

&nbsp;
## reasonus_api_control_thing_under_pointer.lua

Example of `ReaSonus_FP8_ControlThingUnderPointer` which is best used when mapped to a hot key.

## reasonus_api_filter_by_name.lua

Example of `ReaSonus_FP8_FilterByName` which requires you to add one of your filters in order for it to work.

## reasonus_api_get_track_offset.lua

Example of `ReaSonus_FP8_GetTrackOffset` which will show the track offset in a message box.

## reasonus_api_set_fader_mode_multi.lua

Example of multiple API commands which can select any mode from a popup menu.

## reasonus_api_set_fader_mode_single.lua

Example of `API_ReaSonus_FP8_SetFaderMode` which can select any mode from a popup menu using a single API command.
